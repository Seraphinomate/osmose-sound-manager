What OSM is

OSM runs entirely in your browser and talks to the Osmose over Web MIDI. It doesn't edit sounds — the EaganMatrix engine stays where it is. What it gives you is everything around the sound: finding it, organising it, recalling it, and shaping it live with a pedal.

Three things it does that the instrument itself cannot:

  • Search and filter 609 presets instead of scrolling an encoder.
  • Remember macro positions per preset, with named snapshots you can recall.
  • Route an expression pedal to any combination of the six macros, FX Mix and Postgain, each with its own travel range.
Browser support

Chrome or Edge on desktop only. The Web MIDI API is not implemented in Safari or on any iOS/iPadOS browser — on an iPad every browser is Safari underneath, so OSM cannot work there. Firefox requires the MIDI permission prompt to be accepted.

Start

Connect your Osmose

  1. Open osmose-sound-manager_V183.html in Chrome or Edge.
  2. Connect the Osmose over USB and switch it on.
  3. Accept the browser's MIDI permission prompt. If you block it, OSM cannot send anything.
  4. Go to Settings and pick your Osmose Firmware — v2.1 (609 presets), v2.0 (529) or v1.x.
  5. Under MIDI Output, choose port 2. On macOS it appears as Osmose Port 2; on Windows as MIDIOUT2 (Osmose).
  6. Return to Library and click any card. The Osmose should change sound immediately.

The indicator at the top right shows the connection at a glance: green when a port is open, red on error, dim when nothing is selected. Click it to jump straight to Settings.

Port 2 matters

Port 1 carries note data. Preset changes and control messages only reach the sound engine on port 2 — the Haken port. If presets don't switch, this is almost always why.

Tabs

Library

The Library shows every preset as a card. Click a card and OSM sends a Bank Select followed by a Program Change — the Osmose loads the sound. The active card keeps a lit outline.

Search

The search field filters in real time across preset name, type and tags. It combines with the filter bars rather than replacing them.

Three filter levels

Bank, type and character stack with AND logic: a preset must match the selected bank, the selected type, and every active character to stay visible.

Snapshots

A snapshot stores the six macro values and the current Spider routing for a preset. Every preset has its own set.

  • + snap captures the current state as Snap 1, Snap 2…
  • Click a snapshot to recall it and send the values.
  • Right-click or use the snapshot's menu for Rename, Save as preset and Delete.
  • A snapshot pill marks itself as modified once you move a knob away from it.

Per-preset memory

When you leave a preset, its macro values are stored. Coming back restores them and re-sends them to the Osmose about 150 ms after the Program Change. Freeze is the switch that suspends this behaviour.

Tabs · signature feature

Spider — pedal routing

The Osmose sends expression-pedal data, but it can't fan that one pedal out to several destinations with independent ranges. Spider does. One pedal sweep can open a filter macro, pull back Postgain and lift FX Mix at the same time — each on its own travel.

One incoming CC · eight possible destinations · independent ranges

Setting it up

  1. Open the Macro panel and click Pedal to reveal the Spider zone.
  2. Pick the incoming controller under Source CC: Mod Wheel (CC1), Breath (CC2), Foot (CC4), Volume (CC7), Expression (CC11, the default) or Timbre (CC74).
  3. Click a destination to switch it on. Eight are available: M1–M6, FX Mix and Postgain.
  4. Press ▼ MIN and set where each destination sits with the pedal fully up.
  5. Press ▲ MAX and set where it should land with the pedal fully down.
  6. Sweep the pedal. Each destination travels its own range; the ring in the middle tracks the incoming value.

A destination whose MIN is higher than its MAX simply runs backwards — useful for trading one macro against another across a single sweep.

Saved with the snapshot

Spider routing is stored inside the snapshot, not globally. Two snapshots on the same preset can use completely different pedal maps, and switching between them switches the routing too.

Tabs

Playlists

Ordered sets of presets for a set list, a session, or any theme. The sidebar lists them with a colour dot and a count; Favorites mirrors the stars in the Library automatically.

Building one

  1. Click + at the top of the sidebar.
  2. Name it, pick a colour, add an optional description.
  3. From the Library, use a card's ⋮ menu to add presets. One preset can sit in several playlists at once.

Tabs

Discover

One button, one die. Each press picks a random position in the whole preset range and loads it. If the preset exists in your library, its card appears below with name, CC0, PC and tags; if it doesn't, OSM still sends the raw Bank Select and Program Change so you hear it.

The range follows the firmware set in Settings: 609 positions on v2.1, 529 on v2.0. It's the fastest way to stumble into sounds you'd never have filtered your way to.

Saving your work

OSM saves continuously to your browser's local storage under two keys — osm_v1 for presets and playlists, opm_synth_v1 for macros, snapshots, labels and MIDI settings. Older opm_v2 backups are migrated on load.

Local storage is fragile

It belongs to one browser profile. Clearing site data, using private browsing, or opening the file from a different Chrome profile gives you an empty library — the old data isn't lost, it's simply in another bucket you're no longer looking at. Export regularly. It's the only real backup.

The unsaved-changes indicator

Any change since your last export raises a flag: an orange dot on the Export button and a red line in Settings. Closing the tab with the flag raised triggers a browser confirmation first. Export once and both clear.

Empty-session prompt

If OSM starts with no stored data at all, a banner offers to import your osm-session.json straight away. Dismiss it if you really are starting fresh.

Because the export always uses the same filename, you end up with one canonical session file that you overwrite — rather than a folder of dated exports you have to choose between.

Reference

MIDI reference

How a preset is sent

  1. CC0 (Bank Select) with the preset's bank value, between 30 and 34.
  2. Program Change with the preset's program number, 0–127.
  3. About 150 ms later, the macro values stored for that preset are re-sent on CC12–17.

Messages OSM will send

OSM only ever transmits control messages from this list. Anything outside it is blocked before it reaches the instrument, so a stray controller CC can't disturb the EaganMatrix.

12–17 Macros18 Postgain 20–23 FX Params24 FX Mix 26 Pregain64 Sustain 66 Sostenuto 169 Sostenuto 2 83 EQ Tilt84 EQ Freq 85 EQ Mix93 Comp Mix

Each of these can be switched off individually in the CC filter.

If nothing happens

  • Check you selected port 2, not port 1.
  • Check the MIDI channel matches the instrument.
  • Check the firmware setting matches the Osmose — the preset numbering changed between v1.x and v2.x, so a mismatch sends valid messages to the wrong sounds.
  • Reload the page if you connected the Osmose after opening OSM.
