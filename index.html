OSM Sound Manager is a free, browser-based preset manager for the Expressive E Osmose — no installation, no account, no fuss.

Free · v1.0
OSM Sound Manager

Browse your entire preset library, filter by sound character, send patches via MIDI in one click, and remember your macro settings for each preset. All in a single HTML file — open it in your browser and it works.

Full Factory & Expansion 01 library
Filter by type, bank & character tags
Per-preset macro memory & snapshots
Direct MIDI send (Web MIDI API)
Playlist builder & navigation
No install — one HTML file
Download free User manual 100% free · always

Compatible with Osmose firmware v2.1 · Requires Chrome or Edge (Web MIDI)
